##### Batching:

 We added more moving parts

Not accepting write while i'm flushing to database.

Spinning multiple threads across workers is a bad idea.

**Goal: We shouldn't stop consuming**

Map is being shared by two threads, we cannot add element to map while iterating. => keeping map lock will block the intake 

What if we take copy of map data with a lock => ==optimistic way==

we are moving from keeping lock over db operation to ==lock over deep copy==

```
def process(m):
	tags = extract_tags(m)
	for tag in tags:
		m[tag]++
```

Better approach, **we will have active and passive buffers, we will swap in the critical section.**

we will partition by tag at kafka level. This is absolute min number of writes.
